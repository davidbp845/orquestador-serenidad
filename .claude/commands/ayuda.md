---

Lee todos los ficheros `.claude/commands/*.md` de este proyecto (no inventes comandos que no existan como archivo). Para cada uno, extrae del frontmatter `description` y, si lo tiene, `argument-hint`, y preséntalos en una lista breve en español con este formato:

- `/nombre-comando [argumento]` — descripción.

Ordénalos alfabéticamente. No expliques la mecánica interna de cada comando (para eso está `/nombre-comando` en sí) — solo esta lista de referencia rápida. No implementes ni ejecutes nada, es solo listar.
